Remote Code puts the Claude Code sessions running on your Mac in your pocket. Start a session in any project folder, watch Claude think, edit and run commands in real time, and approve or deny every action from your iPhone or iPad.

REQUIREMENTS — PLEASE READ
Remote Code is a remote control, not a standalone assistant. It needs:
• a Mac (macOS 15 or later) running the free Remote Code Mac app, available at github.com/ardasnturk/remote-code
• the official Claude Code command-line tool installed on that Mac and signed in with your own Claude account (or your own API key)
Remote Code never connects to Anthropic and never sees your credentials: all AI work happens in Claude Code on your Mac. You can explore the app first with the built-in demo mode, which needs neither a Mac nor an account.

WHAT YOU CAN DO
• Browse the folders in your Mac's home folder and start a new session in any of them
• Pick the model and the permission mode for each session
• Follow responses, extended thinking, tool calls, file diffs, terminal commands and their output as they stream in
• Approve or deny file edits and shell commands from a clear, readable sheet — or allow a tool for the rest of the session
• Stop a running turn instantly and continue later with full context
• Resume any earlier session; transcripts are cached on your device for offline reading
• Use split view on iPad and keep several Macs paired

PRIVATE AND SECURE BY DESIGN
• Pair with a QR code shown on your Mac — no account, no cloud, no sign-up
• End-to-end encryption between your devices (Noise IK, X25519, ChaCha20-Poly1305) with mutual authentication on every connection
• Revoke a lost device on the Mac in one click
• Unanswered permission requests are denied automatically
• No analytics, no tracking, no ads. Remote Code is open source under the MIT license

WORKS AT HOME AND ON THE GO
On your home or office Wi-Fi your Mac is found automatically. Away from home, Remote Code works over Tailscale, and the Mac app includes a step-by-step assistant to set it up. The Mac app keeps your Mac awake while sessions are running and can optionally stay awake with the lid closed.

ACCESSIBLE AND LOCALIZED
Full Dynamic Type and VoiceOver support, light and dark mode, and translations in English, Turkish and German.
