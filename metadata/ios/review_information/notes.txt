HOW TO REVIEW PILOTHOUSE

Pilothouse is a remote control for the Claude Code command-line tool running on the user's own Mac. A real setup needs a Mac with the free Pilothouse Mac app (distributed outside the Mac App Store as a notarized app: https://github.com/ardasnturk/pilot-house/releases) and a signed-in Claude Code CLI. To make review possible without any of that, the app contains a complete DEMO MODE that simulates a paired Mac inside the app. It needs no account, no network and no Mac.

Start the demo:
1. Launch the app. On the welcome screen tap "Try the Demo".
   (Later it can be switched on or off in Settings → Demo mode.)
2. The session list of the simulated Mac "Demo MacBook Pro" appears. Open "Fix the flaky login test" to see a finished session with tool calls, a file diff and terminal output.
3. Tap "New Chat" (pencil icon, top right), open "Developer" → "weather-app" and tap "Start in ~/Developer/weather-app".
4. Type any message, for example "Make the tests faster", and send it. The simulated assistant streams its reply and tool calls, then asks for permission to edit a file or run a command: a sheet appears with Allow, Deny and "Always allow … in this session". Every choice works.
5. While a reply is streaming, the Stop button ends the turn immediately.

Permissions requested by the app:
• Camera — only to scan the pairing QR code shown on the Mac. The demo does not need it.
• Local Network — to find and connect to the user's own Mac via Bonjour. The demo does not need it.

Data and accounts:
• The app has no accounts, no sign-in, no in-app purchases, no analytics and no third-party SDKs.
• It never connects to Anthropic or any other server: it only talks to the user's own Mac, end-to-end encrypted (Noise IK / ChaCha20-Poly1305). The AI processing happens in Claude Code on the user's Mac under the user's own Claude account.

Encryption export compliance: the app only uses encryption to authenticate and protect the user's own data in transit between their own devices, using Apple CryptoKit; ITSAppUsesNonExemptEncryption is set to NO accordingly.

Trademark: "Claude Code" is named only to describe compatibility. Pilothouse is an independent open-source project (MIT), not affiliated with Anthropic; the app uses its own name, icon and colors.
