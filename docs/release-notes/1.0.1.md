## Pilothouse 1.0.1

Fixes for the first week of use, plus model and effort per chat.

### Fixed

* **Same Wi-Fi without Tailscale** — the iPhone and iPad app now waits for
  iOS's Local Network permission instead of giving up, so it reaches the Mac
  on your home network directly. If the permission is off, the app says so
  and opens Settings for you.
* **`/` in new chats** — the list of skills and commands is filled before the
  first message: the Mac reads them from the project, `~/.claude` and your
  enabled plugins. A new `/` button next to the message field opens it.

### New

* **Effort per chat** — Claude Code low to max, Codex low to extra high. Pick
  it when you start a chat, or set a default in Settings → New chats.
* **Change model and effort in a chat** — tap the model chip in the message
  field (or the session menu). The change applies from the next message.
* **Get the iPhone App** window on the Mac, with the install QR code once the
  TestFlight beta is open.

### Install

Download `Pilothouse-1.0.1.dmg` below (signed with Developer ID and notarized
by Apple), or update with Homebrew:

```sh
brew upgrade --cask pilothouse
```

Update the iPhone or iPad app as well: the new settings need both sides at
1.0.1. An older app keeps working with the new Mac, without the new options.

The full list of changes is in [CHANGELOG.md](https://github.com/ardasnturk/remote-code/blob/main/CHANGELOG.md).
