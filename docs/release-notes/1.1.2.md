## Pilothouse 1.1.2

### Added

* **Allow everything in a chat.** Approving every command of a long task one
  by one is over: the permission sheet has a new **Allow everything in this
  chat** button, and the chat's menu a **Permissions** picker. A chat's
  permission mode can now change at any time, even while a reply runs; with
  "Bypass permissions" the open requests are allowed at once and the chat
  asks no more. "Allow bypass permissions" still has to be turned on in the
  Mac's settings first (Settings → Security).

### Fixed

* **Weekly summary in your language.** The summary was written in the Mac's
  language, and Apple's on-device model sometimes switched to the language of
  your chats, so one summary could mix several languages. It now follows the
  language the iPhone or iPad app is shown in.

Both need the new Mac app and the new iPhone or iPad app.

### Install

Update the iPhone or iPad app through TestFlight. On the Mac, use
**Settings → Updates → Install and Relaunch**, download
`Pilothouse-1.1.2.dmg` below, or run `brew upgrade --cask pilothouse`.

The full list of changes is in [CHANGELOG.md](https://github.com/ardasnturk/pilot-house/blob/main/CHANGELOG.md).
