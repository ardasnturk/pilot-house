## Pilothouse 1.1

A fresh look for both apps, updates from inside the Mac app, photos and videos
in chats, real model names, and ten languages.

### Mac

* **New design** — a gradient menu that shows what needs you now: setup
  problems, approvals, chats and limits. Everything else lives in the new
  **Settings**, a sidebar of panes like System Settings.
* **Updates in the app** — Pilothouse checks GitHub once a day. **Install and
  Relaunch** downloads the new version, verifies its checksum, Apple
  notarization and developer signature, and restarts.
* **A nicer DMG window** with the next steps after installing.

### iPhone and iPad

* **New design** with the brand gradient and glass cards; tool calls, diffs
  and thinking open in sheets, like the Claude and Codex apps.
* **Status inside the message field** — what the agent is doing and for how
  long, with Stop right where Send was.
* **Photos and videos** — attach from the library or the camera; videos are
  sent as a few frames.
* **Real model names and effort levels**, read from Claude Code and Codex on
  your Mac, so the lists always match your CLIs.
* **Ten languages** — English, Türkçe, Deutsch, Español, Français, Italiano,
  Português (Brasil), 日本語, 한국어, 简体中文 — following your device.

### Connection

* **Local network first.** At home Pilothouse never needs Tailscale. Turn on
  "Use Tailscale when away" in the iPhone settings only if you want to reach
  your Mac from elsewhere.

### Install

Download `Pilothouse-1.1.0.dmg` below (signed with Developer ID and notarized
by Apple), update from **Settings → Updates** in Pilothouse 1.1 and later, or use
Homebrew:

```sh
brew upgrade --cask pilothouse
```

Update the iPhone or iPad app as well. New here? The
[Quick start](https://github.com/ardasnturk/remote-code#quick-start) takes five
minutes.

The full list of changes is in [CHANGELOG.md](https://github.com/ardasnturk/remote-code/blob/main/CHANGELOG.md).
