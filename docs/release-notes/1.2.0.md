## Remote Code 1.2.0

### Pilothouse is now Remote Code

New name, new icon (a `>_` prompt with a signal) and a new home:
[github.com/ardasnturk/remote-code](https://github.com/ardasnturk/remote-code)
and [rcode.ardasnturk.com](https://rcode.ardasnturk.com). Nothing has to be set
up again: your paired devices, settings, chats and the Mac's keychain identity
carry over. The Mac app is now called **Remote Code.app**; after the next
update it replaces Pilothouse.app in your Applications folder.

### Added

* **Allow everything in a chat.** The permission sheet has a new **Allow
  everything in this chat** button, and the chat's menu a **Permissions**
  picker. A chat's permission mode can now change at any time, even while a
  reply runs. "Allow bypass permissions" still has to be turned on in the
  Mac's settings first (Settings → Security).

### Fixed

* **Open at login.** The switch in Settings → General could look switched off
  while it was on. It now shows the real state, says when macOS waits for your
  approval in Login Items, and shows errors right there.
* **Weekly summary in your language.** It now follows the language the iPhone
  or iPad app is shown in instead of the Mac's, and no longer mixes languages.

The permission picker and the summary language need the new Mac app and the
new iPhone or iPad app.

### Install

Update the iPhone or iPad app through TestFlight. On the Mac, use
**Settings → Updates → Install and Relaunch**, download
`RemoteCode-1.2.0.dmg` below, or with Homebrew:

```sh
brew update && brew upgrade --cask remote-code
```

(The `pilothouse` cask moves to `remote-code` by itself.)

The full list of changes is in [CHANGELOG.md](https://github.com/ardasnturk/remote-code/blob/main/CHANGELOG.md).
